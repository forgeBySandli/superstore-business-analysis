# Superstore Business Analysis

## Project Overview
Analyzed Global Superstore sales data to improve sales and profitability using MySQL and Excel.

## Tools Used
- MySQL Workbench
- Excel
- GitHub

## Dataset
- train.csv (145 records) - Contains Order, Sales, Profit, Category, Region data.

## Key Business Questions Solved
1. What is Total Sales & Total Profit?
2. Which Category generates highest Sales?
3. Which are Top 5 Most Profitable Products?
4. What is Profit Margin by Region?
5. Sales performance by Customer Segment.

## SQL Queries
All queries are available in `SQL_Queries.sql` file.

## Key Insights (Example)
- Technology Category has highest sales.
- West Region has highest profit margin.
- Consumer Segment is the most frequent buyer.
